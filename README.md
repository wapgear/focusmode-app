# Focus Mode

Keep your attention on one window.

Focus Mode is a macOS menu bar app that dims the background around your active window and blocks clicks outside it. Toggle focus when you need it, or start a timed session.

[Download the latest release](https://github.com/wapgear/focusmode-app/releases/latest)

## What it does

- Keep the active window clear while dimming the rest of the screen.
- Block clicks and scrolling outside the focused window.
- Toggle focus from the menu bar or with a customizable keyboard shortcut.
- Run timed sessions with saved durations and a countdown you can position or hide.
- Choose the background shade's color and opacity.

## Get started

1. Download the `.dmg` from the [latest release](https://github.com/wapgear/focusmode-app/releases/latest).
2. Open it and drag Focus Mode into Applications.
3. Launch Focus Mode. Its icon appears in the menu bar.
4. Choose **Enable Focus Mode** or press **Control + F**.
5. Allow Focus Mode in **System Settings → Privacy & Security → Accessibility** when prompted.

Press Control + F again to turn focus off. Choose **Start Timer…** for a timed session, or **Settings…** to customize the app. Choose **Quit** from the menu bar to exit.

Requires macOS 12 or later. The current download is for Apple silicon Macs. Releases are Developer ID signed and notarized by Apple.
